# خريطة التنفيذ

ننفذ قطاعًا رأسيًا صغيرًا في كل خطوة، حسب بوابات خروج لا تواريخ افتراضية. أول إصدار عام يتطلب اكتمال المسارين. حالات الدعم تُنشر على هيئة منصة/نسخة وميزة مع رابط لدليل التحقق.

| المعلم | العمل | بوابة الخروج |
| --- | --- | --- |
| M0 — تأسيس | عقد مشروع/نية/نموذج وإصدارات، CI يشغل lint/typecheck/tests/build، baseline للشكل الحالي وقرار reuse | مثال مرجعي يُقرأ ويُراجع؛ اختيار توزيع self-hosted |
| M1 — Greenfield | workspace/draft، نموذج يدوي، محرك IPv4/VLAN/port، تعديل وحفظ/فتح، مقارنة بديلين | مشروع فرع يُبنى ويحفظ ويُقارن بلا حساب AI؛ خطأ سعة ظاهر |
| M2 — Brownfield | import JSON canonical ثم subset ملف Cisco، تثبيت baseline، توليد مرشح، semantic diff، تقرير تغطية | إضافة Guest VLAN على fixture مع حفظ الموجود ونتيجة unknown عند مدخل جزئي |
| M3 — لغة ومراجعة | AR/EN extraction وRTL، ربط intent بالفرق، OIDC وتجربة تحكم وصول، مراجعات وexports | كلا المسارين يبدآن بوصف أو form وينتهيان بحزمة مراجعة قابلة للتحقق |
| M4 — دليل تشغيل | محول Cisco مثبت، حزمة change/rollback، تحقق مخبري خارجي، backups وrestore وتحجيم | نجاح حزمة التغيير والتراجع في مثال مختبري، ونشر داخلي قابل لإعادة التشغيل دون blockers مجهولة في عينة التصدير التنفيذي |
| M5 — اتساع ودعم شركات | مورد ثان وفق fixtures ومستخدمين، استيراد inventory/IPAM، تقييم Batfish، scopes أكبر، خيارات cloud | دعم معلن حسب تغطية مثبتة؛ pilot مع مهندسين قبل إطلاق عام |

## تذاكر البداية

| Ticket | المخرج واختباره | يعتمد على |
| --- | --- | --- |
| NT-001 | types + schema v1 ومعالجة fixture؛ يُرفض duplicate/dangling وعنوان سيئ بدون أي API أو DB | لا شيء |
| NT-002 | VLSM keyed by segmentId وrules IP-01/02؛ الحالة المرجعية وحالة /28 تنجح/تفشل كما ينبغي | NT-001 |
| NT-003 | Cisco profile منطقي بسعة ومنافذ مدخلة، وإخراج فرق تعديلات JSON | NT-001 |
| NT-004 | repository لحفظ/فتح revision بIDs مستقرة، tests بمعزل Workspaces | NT-001 |
| NT-005 | شاشة Intake → Plan → Review مع حفظ المسودة وبيان مصدر الحقول | NT-002/003/004 |
| NT-006 | استيراد baseline من fixture canonical، رفض mapping مبهم، وإظهار diff للـGuest | NT-001/003/004 |
| NT-007 | صفحة ثقة/أدلة ومراجعة pinned لrevision وvalidation run | NT-005/006 |

راجع قبل فتح مسار معماري جديد: أثره على المسارين، جزئية يمكن شحنها، وتكلفة صيانتها. إصلاح الحفظ الحالي كإجراء منفصل له قيمة لو التطبيق منشور لأشخاص الآن، وإلا تغطيه إعادة البناء في NT-004.
