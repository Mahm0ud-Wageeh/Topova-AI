# Active AI contract

Conversation inference is implemented in `backend/lib/ai/agent.ts`; deterministic tools are isolated in `agent-tools.ts`. `GEMINI_API_KEY` enables the external conversation engine. Other provider keys are used by topology parsing only. Each inference request has a bounded deadline and caller cancellation; cancellation prevents writing a completed conversation or running the mutating fallback afterward.

External inference receives recent conversation context, the active network, attachments and profile instructions/memory. File content is data, not permission to execute uploaded commands. All resulting workspace data is validated before saving. Mutations to an existing workspace are persisted as proposals and cannot replace the accepted workspace until the user accepts the proposal with a matching conversation version.

Offline chat uses deterministic rules and the current network. Structured routing/VLAN preferences apply when the request has not specified a protocol. Local attachment inspection validates topology JSON, summarizes Cisco/text hostname/interfaces/IP assignments, and reports YAML/CSV as text-only. It does not execute uploaded commands, reconstruct a complete network from a single config, infer conversational memory or interpret arbitrary free-form personal instructions. The UI and response execution mode expose these limits.

Local fallback may produce educational security and reachability results. These are model outcomes, not live telemetry, hardware compatibility tests or a guarantee of security.
