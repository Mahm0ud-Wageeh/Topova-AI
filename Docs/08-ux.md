# تجربة الاستخدام ومواصفات الشاشات

قاعدة الواجهة: كل شاشة تجيب «أنا براجع أنهي نسخة؟ وإيه اللي أكمل بيه؟». مهندس الشبكات يصل للمعلومات النصية كاملة عبر الجداول والمفتش حتى لو الرسم مزدحم. اللغة العربية للمسارات الرئيسية RTL؛ IPv4 وCLI والمعرّفات تعرض LTR داخل الواجهة.

| الشاشة | ما يظهر ويُعمل |
| --- | --- |
| Workspace & Projects | اختيار Workspace، بحث وفلاتر، المرحلة والمالك ووقت آخر تعديل، نقطة دخول واضحة لكل mode |
| Intake | نص AR/EN، نموذج يدوي، حالة AI/offline، اختيار السيناريو؛ Brownfield يطلب ملف/نوع baseline وحدود البيانات |
| Requirements & Coverage | facts مع المصدر، افتراضات قابلة للتعديل، أسئلة المراجعة، تبويب unsupported؛ إجراءات تأكيد منفصلة للـintent والـbaseline |
| Design | الرسم + جداول device/interface/IP، edit drawer وundo للمسودة، إظهار scope، حالات المنافذ والطاقة لو بياناتها متاحة |
| Compare | baseline ثابت / alternative selectors، فرق قابل للفلترة، أثر tagged يدعم jump من finding إلى العنصر |
| Validation | نتائج ثابتة للنسخة، أولوية، أدلة، نطاق، rerun، blockers، وفرق واضح بين unknown وfail ونجاح في المعمل |
| Review & Export | reviewer وسبب القرار، بصمة revision، خيارات export والبوابات المانعة، سجل وتقرير تشغيل/تراجع |

الحالات التي تُصمم قبل بدء التنفيذ: empty، loading/progress، stale revision، partial import، unsupported، request retry، timeout، export failure. المسودة تستمر بعد refresh ويظهر وقت آخر حفظ. المحافظة على النص قبل تسجيل الدخول لا تُفعل إلا وفق سياسة بيانات التشغيل. عناصر الرسم الأساسية تصل لها بالكيبورد أو من جدول مكافئ؛ الحالة لا تعتمد على اللون، ورسائل التحقق ترتبط بالحقول. لا تعرض عينة كأنها مشروع المستخدم. ابدأ desktop للعمل الهندسي، واجعل قراءة التقرير ومراجعة النتائج صالحة على التابلت والموبايل.
